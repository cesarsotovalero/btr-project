BTR's first public pre-release packages the team hackathon prototype for local exploration with synthetic demo data.

## Highlights

- Eight specialist agents for intake, extraction, reconciliation, regulation, risk process, ESG, historical comparison, and decision synthesis.
- Three human review checkpoints, case management, document uploads, analyst chat, and audit traces.
- FastAPI backend, PostgreSQL, Gemini / mock LLM providers, and a SEB Green analyst workspace.
- Generated PDF and Excel fixtures with intentional inconsistencies for exploring the workflow.
- Illustrated README, two-minute demo, and MIT-licensed original application source. Third-party branding, fonts, and media retain their respective rights.

## Try it locally

```bash
git clone https://github.com/cesarsotovalero/btr-project.git
cd btr-project
git checkout v0.1.0
cp .env.example .env
# Edit .env: set POSTGRES_PASSWORD and LLM_BACKEND=mock
make docker-up
```

Open http://localhost:3000 and sign in with the local demo credentials `analyst` / `analyst123`. See the [README](https://github.com/cesarsotovalero/btr-project/tree/v0.1.0#readme) for the architecture, prerequisites, and development setup.

## Validation and limitations

The underlying snapshot passed 114 backend tests, Ruff lint/format checks, and the UI build. This release adds presentation and documentation assets without changing application behavior.

This is a prototype, not a production banking system or a compliance certification. All seeded cases and reference policies are illustrative. Demo authentication defaults are intended for local exploration. The initial npm install reported 10 dependency vulnerabilities; these are not remediated in this release. The retained video received sampled-frame and metadata review, not complete visual/audio clearance. Owner-approved JPG metadata is retained; the presentation and runtime database/uploads are excluded. See `RELEASE_REPORT.md` for the preparation record.
