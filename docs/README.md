# Documentation and hackathon materials

This directory retains the team hackathon specification, demo video, team image, and photographs. These are historical prototype materials; any regulatory or compliance statements describe aspirations, not a compliance certification.

## Project visuals

- `screenshots/`: frames from the retained demo video (case overview, document workspace, risk assessment), with browser chrome cropped.
- `social-preview.png`: 1280 × 640 repository sharing card; vector source in `social-preview.svg`.
- `releases/v0.1.0.md`: first public pre-release notes.

To activate the sharing card, open the repository **Settings → General → Social preview → Edit → Upload an image**, then choose `social-preview.png`.
